# Настройка панели администратора KF Production

1. Создай локальный файл `.env` рядом с `server.js`, скопировав в него `.env.example`.
2. Задай собственные значения `KF_ADMIN_USER` и `KF_ADMIN_PASSWORD`. Используй уникальный длинный пароль и не отправляй его в чат.
3. Для постоянного хранения на сервере задай `KF_DATA_DIR` (аккаунты и каталог) и `KF_MEDIA_DIR` (загруженные медиа) на постоянные диски/каталоги.
4. Запусти сервер командой `npm start` и открой `http://localhost:3000/admin.html`.
5. Войди, заполни данные публикации, загрузи постер и MP4/WebM (до 80 МБ) или укажи прямую HTTPS-ссылку, затем нажми «Опубликовать».

На хостинге переменные задаются в настройках сервиса. Нужен хостинг, который запускает обычное Node.js-приложение через `npm start`. Netlify в статическом режиме не запускает `server.js`, поэтому этот проект с API, аккаунтами и админкой нельзя полноценно запустить там простой загрузкой файлов. Для работы в интернете потребуется отдельный Node.js-хостинг/сервер или полноценная адаптация backend к Netlify Functions и отдельному хранилищу.

В панели API защищены серверной проверкой администратора. Видео и постеры сохраняются в `KF_MEDIA_DIR`, каталог и аккаунты — в `KF_DATA_DIR`. Если на хостинге нет постоянного диска, данные могут пропасть после перезапуска/нового деплоя.
